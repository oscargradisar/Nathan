# Install Nathan (5 steps)

Nathan is free. It uses free AI accounts that you connect yourself. Your keys stay on your computer.

1. **Download** the file for your computer from the [latest release](https://github.com/oscargradisar/Nathan/releases/latest):
   - Windows (most PCs): `windows-x64-setup.exe`
   - Windows on ARM (Snapdragon laptops, Surface Pro X): `windows-arm64-setup.exe`
   - Mac: the `.dmg` file
2. **Install it.**
   - Windows: open the file. If you see "Windows protected your PC", press **More info → Run anyway**. Click through the installer.
   - Mac: open the `.dmg` and drag Nathan into Applications. The first time, right-click Nathan → **Open**.
3. **Open Nathan** from the Desktop icon or the Start menu (Mac: Applications).
4. **Connect two accounts.** Press **Get key** next to a provider (Groq and Gemini are good first picks). Your browser opens on the provider's key page. Sign in for free, create a key and press **Copy**. Nathan picks it up by itself. Do this for a second provider.
5. **Ask something.** Nathan moves to the control room. Type a question, leave the mode on **vote**, and press **Run**. You'll see several AIs answer side by side, then one merged answer.

If a key doesn't arrive by itself, press **Paste key** and paste it in.
