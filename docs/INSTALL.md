# Install Nathan (5 steps)

Nathan is free. It uses free AI accounts that you connect yourself, and your keys stay on your computer.

1. **Download** the file for your computer from the [latest release](https://github.com/oscargradisar/Nathan/releases/latest):
   - Windows (most PCs): `windows-x64-setup.exe`
   - Windows on ARM (Snapdragon laptops, Surface Pro X): `windows-arm64-setup.exe`
   - Mac: the `.dmg` file
2. **Install it.**
   - Windows: open the file. If you see "Windows protected your PC", press **More info → Run anyway** (the installer isn't signed; signing costs money). Click through.
   - Mac: open the `.dmg` and drag Nathan into Applications. The first time, right-click Nathan → **Open**.
3. **Open Nathan** from the Desktop icon or the Start menu (Mac: Applications). It opens on **Accounts**.
4. **Connect two accounts.** Press **Get key** next to a provider (Groq and Gemini are good first picks). Your browser opens on its key page: sign in for free, create a key and press **Copy**. Nathan picks it up by itself. If it doesn't, press **Paste key**. After two, Nathan opens the console.
5. **Ask something.** Type a question and press Enter. Leave it on **Auto**, or pick **Workflow** to watch a team of models split the job and work on it live.

Optional: if you pay for Claude, ChatGPT or Gemini, go to **Accounts → Your premium plans** and press **Install** then **Sign in** for each. They become Nathan's managers (reviews, web research, code review) using your own plan.

Tips: `/` jumps to the command bar, `Alt+1…6` switches sections, and the ♪, ◉ and ⚡ buttons turn sound, voice and lightning on or off.
